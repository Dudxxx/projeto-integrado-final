# Security Auth Skill

- Hash de senha com bcrypt.
- JWT assinado no backend.
- Email validado com regex.
- CPF validado com algoritmo dos dígitos verificadores.
- Senha forte: 8+ caracteres, maiúscula, minúscula, número e símbolo.
- Não permitir alteração de email no perfil.
- Não permitir acesso sem JWT.
- Não ler nem expor `.env` e segredos.
